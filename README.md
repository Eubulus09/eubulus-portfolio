# Emmanuel Eubulus — Portfolio

A hand-coded portfolio for frontend developer Emmanuel Eubulus, plus a case study for FreshKeep, a Windows app built in C++17.

## Pages

- `index.html` — portfolio: work, about, toolkit, and contact.
- `freshkeep.html` — FreshKeep case study.
- `src/freshkeep.png` — FreshKeep screenshot used in the work grid and case study.

## Run locally

Open `index.html` directly, or serve the folder:

```
python -m http.server 8000
```

Then visit http://localhost:8000.

## Deploy

This site is published with GitHub Pages from the `main` branch:

https://eubulus09.github.io/eubulus-portfolio/

No build step is required. Push changes to `main` and GitHub Pages updates automatically.

## Notes

- Fonts are loaded from Google Fonts.
- Stock photography in the concept cards is loaded from Unsplash.
- `.nojekyll` tells GitHub Pages to serve files as-is.
